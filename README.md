## 📌 Overview

WC26 Fan Intelligence is an interactive football dashboard built around the expanded 2026 FIFA World Cup format.

The application explores tournament information through group standings, knockout bracket simulations, player statistics, data visualizations, and searchable team and squad information.

Built independently in under two weeks, the project demonstrates frontend architecture, TypeScript development, interactive UI design, data visualization, and application state management.

### Tournament Format

- 48 participating teams
- 12 groups
- 104 scheduled matches
- Round of 32 through the Final

---

## ✨ Features

### 🏟 Tournament Standings

- Group standings across all 12 groups
- Color-coded qualification indicators
- Organized team and tournament information

### 🏆 Knockout Bracket Simulator

- Interactive knockout bracket
- Progression from Round of 32 to the Final
- Editable match scores and simulated progression

### 📊 Football Analytics

- Data visualizations built with Recharts
- Tournament and team comparisons
- Confederation and squad-related insights

### 🔎 Unified Search

- Fuzzy search powered by Fuse.js
- Searchable players, coaches, and national teams
- Fast client-side filtering

### ⚽ Player Statistics

- Player-focused tournament information
- Golden Boot tracking interface
- Interactive statistics presentation

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Ifeoluwa00dev/WC26.git
   ```

2. Navigate into the project:

   ```bash
   cd WC26
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Environment Configuration

If your version of the application requires environment variables, configure them according to the project's source code and deployment settings.

Do not commit API keys or other sensitive credentials.
